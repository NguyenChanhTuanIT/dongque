# Exports

Files converted from the game's `.bin` assets for editing in Blender or other
glTF tools. The game does not load anything from this folder.

## characters/kid.glb

Made by `tools/export-kid-glb.html` (`npm run dev`, then open
http://localhost:5173/tools/export-kid-glb.html). Contents:

- the kid mesh from `kid.bin`, skinned to the 22 bones of `kid-bones.bin`,
  renamed `hips`, `spine`, `chest`, `neck_base`, `neck`, `head`,
  `clavicle_R/L`, `upperarm_R/L`, `forearm_R/L`, `hand_R/L`, `thigh_R/L`,
  `shin_R/L`, `foot_R/L`, `toe_R/L`;
- vertex colors (`COLOR_0`) baked from the toon ramps (`ramps.png`, lit side),
  plus the raw ramp info in `_COLORINFO` (x = ramp row, y = 0 fixed, 1 skin,
  2 player color);
- animations `idle`, `run`, `jump`, `bored` (from `kid-*.bin`) and the
  procedural emotes of `src/scene/emotes.ts` (`wave`, `clap`, `dance`, `sit`,
  `fish`, `prone`, `sunbathe`, `guitar`, `kite`, `icecream`, `highfive`).
